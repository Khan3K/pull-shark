A repository used to earn the **GitHub Pull Shark achievement** (16 merged pull requests).

## 🏆 GitHub Achievements

This repo helps you earn **Pull Shark** and other GitHub profile badges. Learn how to get all badges:

📖 **[Complete GitHub Badges Guide →](GITHUB_BADGES.md)**

### Quick Start: Earn Pull Shark

1. Fork this repository
2. Create a new branch
3. Make a small change (fix a typo, add a line)
4. Commit and push
5. Open a Pull Request
6. Get it merged (or merge it yourself)
7. Repeat to reach 16 merged PRs for **Bronze tier!**

### 🦈 Pull Shark Tiers

| Tier | Merged PRs Required |
| --- | --- |
| Default | 2 |
| Bronze | 16 |
| Silver | 128 |
| Gold | 1024 |

### 🎯 Other Earnable Badges

| Badge | How to Earn |
| --- | --- |
| **Quickdraw** | Close an issue/PR within 5 minutes |
| **YOLO** | Merge a PR without any code review |
| **Starstruck** | Get 16 stars on any repository |
| **Galaxy Brain** | Get 2 answers accepted in [GitHub Community Discussions](https://github.com/orgs/community/discussions/) |
| **Pair Extraordinaire** | Co-author a commit in a merged PR |
| **Public Sponsor** | Publicly sponsor someone via [GitHub Sponsors](https://github.com/sponsors) |

💡 **Tip:** You can earn **YOLO** and **Pull Shark** at the same time by merging your own PR without waiting for reviews!
