## 🚀 Start Here: Earn Pull Shark

**Pull Shark** 🦈 is awarded when you merge pull requests. It is one of the most satisfying GitHub achievements — and this repo exists to help you get it.

> 💡 **Goal of this repo:** reach **🥉 Bronze** by merging **16 pull requests**. You are already on your way with every PR you open here!

### What is Pull Shark?

| | |
|---|---|
| **Badge** | 🦈 Pull Shark |
| **Unlocked by** | Merging **2+** pull requests |
| **Difficulty** | 🟡 Medium |
| **Tiers** | 🐣 Default → 🥉 Bronze → 🥈 Silver → 🥇 Gold |

### 7-Step Quick Start

1. **Fork** this repository to your account.
2. **Clone** it (or edit directly on GitHub).
3. **Create a branch** — e.g. `git checkout -b my-pr-1`.
4. **Make a small change** — fix a typo, add a line, edit `CHANGES.md`.
5. **Commit & push** the change to your branch.
6. **Open a Pull Request** back to `Khan3K/pull-shark`.
7. **Merge it** (or have it merged) → 🎉 +1 merged PR!

> ✅ **Pro Tip:** Repeat steps 3–7. Every merged PR counts toward your shark.

## 🏆 All GitHub Achievements

A complete reference of every earnable GitHub achievement.

### Master List

| Badge | How to Earn | Difficulty |
|-------|-------------|------------|
| 🦈 **Pull Shark** | Merge at least **2 pull requests** | 🟡 Medium |
| ⭐ **Starstruck** | Your repository reaches **16 stars** | 🔴 Hard |
| ⚡ **Quickdraw** | Close an issue or PR **within 5 minutes** of opening | 🟢 Very Easy |
| 😎 **YOLO** | Merge a PR **without any code review** | 🟢 Easy |
| 🧠 **Galaxy Brain** | Get **2 answers accepted** in [GitHub Discussions](https://github.com/orgs/community/discussions/) | 🟡 Medium |
| 🧑‍🤝‍🧑 **Pair Extraordinaire** | **Co-author a commit** in a merged PR (GitHub Desktop) | 🔴 Hard |
| 💖 **Public Sponsor** | **Publicly sponsor** someone via [GitHub Sponsors](https://github.com/sponsors) | 🟢 Very Easy |
| 💗 **Heart On Your Sleeve** 🧪 | React with ❤️ to a GitHub post/comment *(testing)* | 🟢 Very Easy |
| 🌐 **Open Sourcerer** 🧪 | PRs merged in **>1 public repo** *(testing)* | 🟡 Medium |

| ⭐ Starstruck | 16 ⭐ | 128 ⭐ | 512 ⭐ | 4096 ⭐ |
| 🧠 Galaxy Brain | 2 answers | 8 answers | 16 answers | 32 answers |

### Step-by-Step Guides

<details>
<summary>🦈 Pull Shark — merge pull requests</summary>

1. Open a **public** repository (like this one).
2. Make a small change on a **new branch**.
3. Open a **Pull Request** and merge it.
4. Repeat until you reach the required count (2 for the base badge).

</details>

<details>
<summary>⭐ Starstruck — 16 stars</summary>

1. Create a **useful public repository** (tool, guide, template, list).
2. Write a clear README with examples and screenshots.
3. Share it on social media, forums, and communities.
4. Ask people to ⭐ star it.

</details>

<details>
<summary>⚡ Quickdraw — close within 5 minutes</summary>

1. Open an issue or pull request.
2. Wait a few seconds.
3. Close it **within 5 minutes** of opening.

</details>

<details>
<summary>😎 YOLO — merge without review</summary>

1. Create a pull request.
2. **Do not** request or wait for any review.
3. Click **Merge pull request** directly.
4. Do this on your own repos (branch protection may block it elsewhere).

</details>

<details>
<summary>🧠 Galaxy Brain — accepted discussions</summary>

1. Go to [GitHub Discussions](https://github.com/orgs/community/discussions/).
2. Find questions you can answer.
3. Write a clear, helpful answer.
4. Get **2 of your answers accepted** by the asker.

</details>

<details>
<summary>🧑‍🤝‍🧑 Pair Extraordinaire — co-authored commit</summary>

1. Download **GitHub Desktop**.
2. Make a commit with a collaborator (or a second account).
3. Add `Co-authored-by: Name <email>` to the commit message.
4. Merge a PR containing that co-authored commit.

</details>

<details>
<summary>💖 Public Sponsor — sponsor openly</summary>

1. Go to [GitHub Sponsors](https://github.com/sponsors).
2. Choose any developer or organization.
3. Sponsor them (even a small amount).
4. Keep the sponsorship **public**.

</details>

> 💗 **Heart On Your Sleeve** & 🌐 **Open Sourcerer** are in testing — requirements may change.

## 🛡️ README Badges Shield Guide

**README badges** (shields) are small SVG images showing repository metadata. They make any project look polished.

### Services

| Service | URL |
|---------|-----|
| **Shields.io** | https://shields.io |

### Common Examples

**Repository stats**
```markdown
![Stars](https://img.shields.io/github/stars/Khan3K/pull-shark?style=social)
![Forks](https://img.shields.io/github/forks/Khan3K/pull-shark?style=social)
![Issues](https://img.shields.io/github/issues/Khan3K/pull-shark)
![Pull Requests](https://img.shields.io/github/issues-pr/Khan3K/pull-shark)
```

**Build & CI**
```markdown
![Build](https://img.shields.io/github/actions/workflow/status/Khan3K/pull-shark/ci.yml)
```

**Version & License**
```markdown
![License](https://img.shields.io/github/license/Khan3K/pull-shark)
![Version](https://img.shields.io/badge/version-1.0.0-blue)
```

**Dynamic**
```markdown

![Last Commit](https://img.shields.io/github/last-commit/Khan3K/pull-shark)
```

### Custom Badge Format
```
https://img.shields.io/badge/<LABEL>-<MESSAGE>-<COLOR>
```
Example: `https://img.shields.io/badge/status-active-brightgreen`

### Colors

| Color | Code |
|-------|------|
| Bright Green | `brightgreen` |
| Green | `green` |
| Yellow | `yellow` |
| Orange | `orange` |
| Red | `red` |
| Blue | `blue` |
| Light Grey | `lightgrey` |
| Grey | `grey` |

### Styles & Logos
- **Styles:** add `?style=` → `flat` (default), `flat-square`, `for-the-badge`, `social`, `plastic`
- **Logos:** add `&logo=<name>` (e.g., `github`, `python`, `npm`)

```markdown
![GitHub](https://img.shields.io/badge/GitHub-Profile-black?style=flat&logo=github)
```

### Placement Tips
- Group related badges (build, tests, coverage) together.
- Put badges at the **top** of the README.
- Use **consistent styling** across all badges.
- 5–8 badges is usually enough — do not overload.

## 💡 Tips to Earn Faster

- ✅ **Pull Shark + YOLO:** Merge unreviewed PRs on your own repos — get both at once.
- ✅ **Pull Shark + Quickdraw:** Open a PR and merge it within 5 minutes — two badges in one action.
- ✅ **Use test repos** (like this one) to safely practice the PR workflow.
- ✅ Keep a repo with a **great README** — it attracts stars (Starstruck) and shares.
- ✅ Be active in **community discussions** — good answers get accepted (Galaxy Brain).
