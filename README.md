## 🏆 What are GitHub Achievements?

**Achievements** are badges that appear on your GitHub profile. They automatically unlock when you perform certain activities — like merging pull requests, answering discussions, or sponsoring open source projects. They celebrate your contribution to the GitHub community.

By default, achievements are **publicly visible** on your profile. You can hide them anytime (see [How to Display or Hide Achievements](#how-to-display-or-hide-achievements)).

## 🦈 This Repo — Pull Shark Practice

This repository helps you earn **Pull Shark** and other GitHub profile badges.

### Quick Start: Earn Pull Shark

1. Fork this repository
2. Create a new branch
3. Make a small change (fix a typo, add a line)
4. Commit and push
5. Open a Pull Request
6. Get it merged (or merge it yourself)
7. Repeat to reach 16 merged PRs for **Bronze tier!**

## 🎯 How to Earn Each Badge — Step by Step

### 🦈 Pull Shark (merge pull requests)

1. Open a **public** repository (like this one).
2. Make a small change (fix a typo, add a line, etc.).
3. Commit the change on a **new branch**.
4. Open a **Pull Request** and merge it.
5. Repeat until you reach the required number of merged PRs (2 for the base badge).

### ⭐ Starstruck (16 stars)

1. Create a **useful public repository** — a tool, guide, template, or awesome list.
2. Write a clear README with usage examples and screenshots.
3. Share your repo on social media, forums, and communities.
4. Ask people to ⭐ star it.

### ⚡ Quickdraw (close issue/PR within 5 minutes)

1. Open an issue or pull request.
2. Wait a few seconds.
3. Close it **within 5 minutes** of opening.

### 😎 YOLO (merge PR without review)

1. Create a pull request.
2. **Do not** request or wait for any code review.
3. Click **Merge pull request** directly.
4. Note: some repos have branch protection that requires reviews — do this on your own repos.

### 🧠 Galaxy Brain (2 accepted discussion answers)

1. Go to [GitHub Community Discussions](https://github.com/orgs/community/discussions/).
2. Find questions you know how to answer.
3. Write a clear, helpful answer.
4. Have **2 of your answers accepted** by the asker.

### 🧑‍🤝‍🧑 Pair Extraordinaire (co-authored commit)

1. Download **GitHub Desktop**.
2. Make a commit together with someone (or a second account).
3. Co-author the commit by adding `Co-authored-by:` to the commit message.
4. Merge a pull request that contains the co-authored commit.

### 💖 Public Sponsor

1. Go to [GitHub Sponsors](https://github.com/sponsors).
2. Choose any open source developer or organization.
3. Sponsor them (even a small amount).
4. Make sure the sponsorship is set to **public**.

## ⚙️ How to Display or Hide Achievements

1. Click your **profile photo** (top-right corner).
2. Go to **Settings** → **Profile** (or **Achievements** section).
3. Check/uncheck which achievements you want to show on your profile.

To change the **emoji skin tone** of your achievements:

1. **Settings** → **Appearance**.
2. Scroll to **Emoji skin tone preference**.
3. Pick your preferred tone — it applies globally to all emojis on GitHub.

## 💡 Quick Tips to Earn Badges Faster

- ✅ **Pull Shark + YOLO together:** Merge unreviewed PRs on your own repos — earn both badges at once.
- ✅ **Pull Shark + Quickdraw together:** Open a PR, merge it within 5 minutes — two badges in one action.
- ✅ **Use test repositories** (like this one) to safely practice the PR workflow.
- ✅ Keep a repository with a **great README** — it attracts stars (Starstruck) and shares.
- ✅ Participate actively in **community discussions** — helpful answers get accepted (Galaxy Brain).
